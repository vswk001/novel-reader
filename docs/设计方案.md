# 墨阅（MoYue）— 本地小说阅读器 · 设计方案

> 版本：v1.0 · 日期：2026-10-22 · 平台：Android 7.0+（minSdk 24，targetSdk 36）

## 1. 产品定位

一款**纯本地**小说阅读器：不联网、无账号、无广告，专注把用户手机里已有的
TXT 小说读得舒服。核心体验对标「静读天下 / Moon+ Reader / 阅读」的本地阅读部分。

设计原则：

1. **离线优先**：所有数据存本机，导入即将文件拷贝进应用私有目录，撤权/删源文件不影响阅读。
2. **省电流畅**：阅读界面零轮询、按需分页、大文件按字节区间懒加载。
3. **中文场景优化**：GBK/GB18030/UTF-8/UTF-16 自动识别，中文章节正则，全角排版。
4. **隐私**：申请权限极少（无网络权限、无存储运行时权限，全部走系统 SAF 选择器）。

## 3. 技术选型

| 项 | 选择 | 理由 |
|---|---|---|
| 语言 | Kotlin 2.0.21 | 官方首选；Compose 编译器随语言版本走 |
| UI | Jetpack Compose + Material 3 | 声明式 UI，书架/菜单开发效率高；分页用 `TextMeasurer`（内部 StaticLayout）保证测量精准 |
| 构建 | AGP 8.13.0 + Gradle 8.14.3 + JDK 17 | 本机工具链现成（`D:\workspace\android-tools`），AGP 8.13 支持 compileSdk 36 |
| 架构 | 单 Activity + Navigation Compose + MVVM | 页面少、跳转简单，不需要多模块 |
| 数据库 | Room 2.6.1（KSP） | 书籍元数据/章节索引/书签/统计，Flow 驱动 UI |
| 偏好 | DataStore Preferences | 设置项 KV 存储，响应式 |
| 序列化 | kotlinx.serialization | 备份 JSON 导出/导入 |
| 依赖注入 | 手写 ServiceLocator（`object Graph`） | 规模小，引 Hilt 得不偿失 |
| 异步 | Coroutines + Flow | 标准 |

不引网络库（app 无 `INTERNET` 权限，从 Manifest 层面保证纯离线）。

### 导入管线（关键流程）

```
SAF Uri ──读字节──> CharsetDetector(BOM/严格UTF-8探测/GB18030兜底)
        ──解码──> TextNormalizer(\r\n统一/去行尾空白/压缩空行)
        ──落盘──> files/books/{id}.txt（UTF-8）
        ──ChapterParser（多正则竞选 + 兜底分段）──> 章节表(char/byte 偏移)
        ──Room 插入 books/chapters ──> 书架可见
```

SAF 权限是临时的，所以**导入即拷贝**到私有目录，之后读取不依赖任何权限。

## 6. 关键技术设计

### 6.1 编码检测（CharsetDetector）
1. BOM 判定：UTF-8/UTF-16LE/UTF-16BE。
2. 无 BOM：整段**严格 UTF-8 校验**，全部合法 → UTF-8；任一非法字节 → GB18030。
3. GB18030 解码失败（极端脏数据）→ UTF-8 容错替换。已覆盖 99% 中文 TXT 场景。

### 6.2 章节识别（ChapterParser）
候选正则集（`^\s*` 开头限定行首）：
- `第[0-9〇零一二两三四五六七八九十百千万]+[章节卷集部回篇]`
- `Chapter \d+` / `序章|楔子|尾声|后记|番外|正文|结局`
- `卷[0-9一二...]+`、`[0-9]{1,4}[、.．][^\d\n]{1,30}$` 纯数字编号行

**竞选策略**：全部试跑，按“章节数≥3、平均章节长 2k~80k 字、标题占比正常”打分取最优；
全部不合格 → 按 10 万字分段命名“第 X 部分”，保证任何书都能读。

### 6.3 分页引擎（PaginationEngine）
- 输入：章节文本（UTF-8 按字节区间读取）、TextStyle、页面像素宽高。
- 算法：`TextMeasurer.measure` 一次测整章（内部 StaticLayout，高度不限），
  逐行累加行高找出**每页最后一行**，`getLineEnd(visibleEnd)` 得到精确换页字符位。
- 缓存：`bookId+chapter+排版参数` 为键的内存 LRU，仅缓存当前章±1 章；
  排版参数变化即失效重排。
- 进度与页面解耦：持久化存 `charOffset`，重排后按偏移重定位页码。

### 6.4 阅读器交互
- `HorizontalPager` 承载页序列；叠加透明点击层：左 28% 上一页、右 28% 下一页、
  中间 44% 呼出菜单（菜单开时点击层关闭）。
- 翻页动画：`currentPageOffsetFraction` 驱动 graphicsLayer —— 滑动(平移)/
  覆盖(上层平移+阴影)/淡入(alpha)/无。
- 音量键：`MainActivity.dispatchKeyEvent` → `Graph.volumeKeyHandler`（由阅读页注册）。
- 亮度/常亮/沉浸：`Window` 属性 + `WindowInsetsControllerCompat`，DisposableEffect 挂接。
- 时长统计：onResume/onPause 差值累计写入 `read_stats` 与 `books.readTimeMillis`。

### 6.5 隐私空间（v1.2.0）
- **入口手势**：书架列表 `NestedScrollConnection` 捕获顶部继续下拉的位移（阻尼累积，
  上限 0.62 屏），过 0.5 屏视为"武装"，顶部提示在「下拉进入隐私空间/松开进入隐私空间」
  间切换并显示进度条；松手（onPreFling）回弹动画，武装状态则触发进入。
- **密码**：数字（4-8 位）/ 图案（3x3 连线 ≥4 点）两种；PBKDF2WithHmacSHA1
  6 万次迭代 + 16 字节随机盐 + 常量时间比较，存独立 DataStore（不进 Room、不进备份）。
- **数据隔离**：`books.space` 字段（Room v1→v2 ALTER TABLE 迁移，旧数据保留在普通空间）；
  书架/统计/导入全部按 space 过滤；长按可跨空间转移（文件与进度不变）。

## 8. 权限与安全

Manifest 仅声明无危险权限；文件访问全部通过 SAF（用户主动授权的 Uri），
无 `READ_EXTERNAL_STORAGE`、无 `INTERNET`。备份导出使用
`CreateDocument`/`OpenDocument`，同样零权限。

隐私空间：书架下拉手势 + 密码验证进入（见 6.5），密码哈希存独立 DataStore，
不进入备份文件；两空间书籍完全隔离。防截屏开关（FLAG_SECURE，截屏黑屏、
最近任务无预览）为设置中的独立选项，可与隐私空间配合使用。

## 11. 风险与对策

| 风险 | 对策 |
|---|---|
| 超大文件（>50MB TXT） | 字节区间懒加载章节，绝不整本驻留内存 |
| 章节 0 识别 | 兜底按字数分段，永远可读 |
| 排版参数变化导致进度漂移 | 进度存字符偏移而非页码 |
| 部分 ROM 禁改系统亮度 | 手动亮度仅作用于本应用窗口（合法行为），失败静默忽略 |
